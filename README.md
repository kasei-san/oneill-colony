# O'Neill Colony

Three.js で作った、オニール型スペースコロニー（島3号型）の内側を歩き回れるデモ。
半径3km・長さ16kmの円筒の内側に街があり、昼は外側のミラーが反射した太陽光で照らされ、夜はミラーが窓に閉じる。

## 起動

```sh
python3 -m http.server 8917
```

ブラウザで http://localhost:8917/ を開く（Three.js r170 を CDN から読み込むのでネット接続が必要）。
重いときは `?q=low` を付ける。

## 操作

| キー | 動作 |
|---|---|
| ドラッグ | 視点 |
| WASD / 矢印 | 移動（Shift で高速） |
| E・Space / Q・C | 上昇 / 下降 |
| G | ガイドツアー（約7分のデモ。ループ。`?demo` を付けて開くと自動で始まる）。ツアー中は Space で一時停止、← → で前後の場面、Esc で終了（右下のボタンでも操作できる） |
| O | 宇宙からコロニーを見る（ドラッグで回り込み、ホイールで距離） |
| N | 昼⇔夜（ミラーが開閉して約8秒で切替） |
| [ / ] | 画角 |
| B | ポストエフェクトのオン・オフ |
| T | トーンマップ ACES ⇔ AgX |
| M | 環境音のミュート（最初のクリックで再生開始） |
| H | パネル表示の切替 |

右上のボタンで各地点にワープ、左下の展開図をクリックすると任意の地点にワープする。

## 世界の構成

- 陸地3枚とガラス窓3枚が60°ずつ交互に並ぶ。窓には橋がかかり、車と環状鉄道が通る
- 街区ごとに都心・中層・住宅・公園・川。遠景は高層ビルだけ残し、地面テクスチャに屋根や道路を焼き込んでいる
- 中心軸（無重力帯）を貨物船・旅客船・シャトルと高速電車が往復する
- 外から見るとコロニーは1Gを作る速さ（約110秒で1回転）で自転している。-z 端に宇宙船の入口があり、点滅する誘導灯の列に沿って推進剤で飛ぶ宇宙船が出入りする。自分を含めた6基の同型コロニーが半径80kmの輪になって並んでいる
- カメラ周辺だけ、形のある車（乗用車・バス・トラック）、歩行者、鳥、建物の細部、細かい木を出す

## 構成ファイル

- `index.html` — 本体（HTML・CSS・JS が1ファイル）
- `docs/research.md` — 低ポリゴンで広い世界をきれいに見せる手法の調査メモ
- `docs/history.md` — コロニー「ネオ・ミヤギ」の架空の歴史・地区のエピソード（ガイドツアーの設定のもと）
- `tools/check.mjs` — ヘッドレス Chrome での動作確認スクリプト（下記）

## 動作確認

```sh
cd tools && npm install
node check.mjs /tmp/oneill-check --presets 0,1,6 --input        # 昼
node check.mjs /tmp/oneill-check --presets 3,4,6 --night        # 夜
```

コンソールエラーの有無・FPS・各地点のスクリーンショットを出力する（別ターミナルでサーバー起動が必要）。
