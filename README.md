# O'Neill Colony

Three.js で作った、オニール型スペースコロニー（島3号型）の内側を歩き回れるデモ。
半径3km・長さ16kmの円筒の内側に街があり、昼は外側のミラーが反射した太陽光で照らされ、夜はミラーが窓に閉じる。
架空のコロニー「ネオ・ミヤギ」を案内する約7分半のガイドツアー（BGM付き）と、スマホ縦長・約1分のダイジェスト版がある。

公開ページ: https://kasei-san.com/oneill-colony/ （ガイドツアー: `?demo`、縦長ダイジェスト: `?sns`）

## 起動

```sh
python3 -m http.server 8917
```

ブラウザで http://localhost:8917/ を開く（Three.js r170 を CDN から読み込むのでネット接続が必要）。
重いときは `?q=low`、ガイドツアーから始めるときは `?demo`、スマホ縦長の約1分のダイジェストは `?sns` を付ける（どちらもクリックで開始。ブラウザがクリック前に音を出させないため）。縦長の画面で開くと自動で `?sns` と同じ縦長ダイジェストの開始画面になる（`?pc` で通常表示）。
コロニーの歴史は http://localhost:8917/history.html で読める。

## 操作

| キー | 動作 |
|---|---|
| ドラッグ | 視点 |
| WASD / 矢印 | 移動（Shift で高速） |
| E・Space / Q・C | 上昇 / 下降 |
| G | ガイドツアー（全31場面・約7分半、ループ）。ツアー中は Space で一時停止、← → で前後の場面、Esc で終了（右下のボタンでも操作できる） |
| O | 宇宙からコロニーを見る（ドラッグで回り込み、ホイールで距離） |
| N | 昼⇔夜（ミラーが開閉して約8秒で切替） |
| [ / ] | 画角 |
| B | ポストエフェクトのオン・オフ |
| T | トーンマップ ACES ⇔ AgX |
| M | 音のミュート（最初のクリックで再生開始） |
| H | パネル表示の切替 |

右上のボタンで各地点（★は観光名所）にワープ、左下の展開図をクリックすると任意の地点にワープする。「街区めぐり」は押すたびに次の種類の街区へ移る。

## 世界の構成

- 陸地3枚とガラス窓3枚が60°ずつ交互に並ぶ。窓には橋がかかり、車と環状鉄道が通る。外のミラーは細い板を並べたすだれ状
- 宇宙港側の端（-z）から奥へ **農業区画 → 工業地帯 → 旧市街 → 新市街** の帯に並ぶ（+z 端も農業区画）
  - 工業地帯: のこぎり屋根の工場・球形ガスタンク・発電所（煙突と冷却塔）・窓のない倉庫
  - 旧市街: クーロン風の古いアパートがひしめく貧民街。再開発ビルと、「再開発反対」の横断幕に囲まれた再開発予定地がある
  - 新市街: 都心・中層・住宅・公園・川・歓楽街（ネオン看板と広告スクリーン）・商店街・学校・寺社と鎮守の森・病院/大学・団地
- 鉄道: 環状線（横）と陸地中央の高架線（縦）。駅は等間隔で、電車はランダムに停車する。2本が交わる所は必ずターミナル駅で、まわりはオフィス街・歓楽街・未発展のいずれか
- 観光名所: 新造船所（軸のそばで船を組み立て、完成した船が宇宙港へ出ていく）、コロニー中央駅（もとは旧造船所。軸の真ん中の蜂の巣状の駅とスポーク状のエレベーター）、無重力パークと駅、リング大観覧車と遊園地、川沿いの屋台通り、蓋をのぼるエレベーター、拡張境界地区と旧市街
- 中心軸（無重力帯）を貨物船・旅客船・シャトルと高速電車（新造船所・中央駅・無重力パークの3駅に停車）が往復する。3駅からはそれぞれ6本のスポーク状エレベーターが地面へ伸びる
- 外から見るとコロニーは1Gを作る速さ（約110秒で1回転）で自転している。-z 端に宇宙船の入口があり、赤く明滅する誘導灯の列に沿って推進剤で飛ぶ宇宙船が出入りする。自分を含めた6基の同型コロニーが半径80kmの輪になって並ぶ
- カメラ周辺だけ、形のある車（乗用車・バス・トラック）、歩行者、鳥、建物の細部、細かい木を出す
- 夜: 窓明かり・街灯・車の光の流れ・公園のライトアップ・歓楽街のネオン・観覧車とコースターの電飾

## 構成ファイル

- `index.html` — 本体（HTML・CSS・JS が1ファイル）
- `history.html` — `docs/history.md` を読み込んで表示するページ
- `docs/history.md` — コロニー「ネオ・ミヤギ」の架空の歴史・地区のエピソード（ガイドツアーの設定のもと）
- `docs/research.md` — 低ポリゴンで広い世界をきれいに見せる手法の調査メモ
- `tools/` — ヘッドレス Chrome での動作確認スクリプト（下記）

## 動作確認

別ターミナルでサーバーを起動した状態で:

```sh
cd tools && npm install
node check.mjs /tmp/oneill-check --presets 0,1,6 --input     # 昼。ワープ先のスクリーンショット・FPS・エラー数・操作テスト
node check.mjs /tmp/oneill-check --presets 3,4,6 --night     # 夜
node tour-shots.mjs /tmp/tour '[["旧市街",3000],["ターミナル駅",3000]]'   # ガイドツアーの場面を見出しで指定して撮る（--night で夜）
node tour-loop.mjs                                            # ガイドツアーが全場面進んでループするか
node record-sns.mjs ../out/oneill-colony-sns.mp4             # SNS 用の縦長動画（1080x1920・30fps・BGM付き・15場面77秒）を書き出す（書き出しに約2分かかる）
```
